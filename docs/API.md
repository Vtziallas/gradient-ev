# Gradient — API Specification

Base: `https://api.gradient.app/v1` — JSON, OpenAPI generated by FastAPI, versioned by URL
path. Auth: `Authorization: Bearer <JWT>` unless marked public. Errors: RFC 9457
`application/problem+json` with stable `type` slugs. Idempotency: mutating endpoints accept
`Idempotency-Key`. Rate limits per tier (see Security.md) via `X-RateLimit-*` headers.

## 1. Auth

| Method | Path | Notes |
|---|---|---|
| POST | `/auth/register` | email+password (argon2id) → tokens |
| POST | `/auth/login` | → `{access_token (15 min), refresh_token (60 d, rotating)}` |
| POST | `/auth/oauth/{apple\|google}` | id_token exchange |
| POST | `/auth/refresh` | rotation + family reuse detection |
| POST | `/auth/logout` | revokes refresh family |
| DELETE | `/users/me` | GDPR erasure (grace period) |
| GET | `/users/me/export` | GDPR export (async job → signed S3 URL) |

## 4. Drive session (WebSocket)

`WSS /drive/session?route_id=…` — one connection per active trip.

Client → server (every 15 s, batched 1 Hz samples):
`{"t":"telemetry","samples":[{"ts":…,"lat":…,"lng":…,"speed":…,"soc":…?}]}`

Server → client (1 Hz max, delta-encoded):

```jsonc
{ "t": "twin",
  "route_s_m": 45200, "segment_class": "heavy",
  "soc_now": 64.2, "arrival_soc": 21.1,           // smoothed per contract
  "power_kw": 24.6, "slope_pct": 5.1,
  "next": { "event": "summit", "in_m": 3400, "then": "regen_8km" },
  "speed_band": {"min_kmh": 72, "max_kmh": 79},
  "voice_cue": "Reduce to about 75 for this climb — you'll save 1.2%"?  }
```

Also: `{"t":"reroute", …}`, `{"t":"charge_update", …}`, heartbeat ping/pong 20 s,
resume token for reconnect without losing twin state (state in Redis, TTL 2 h).

## 6. Contract governance

- OpenAPI schema is committed (`openapi.json`) and diffed in CI; breaking change ⇒ new
  version path.
- Mobile/web clients are generated from the schema (Dart: `openapi-generator`;
  TS: `openapi-typescript`) — no hand-written DTOs.
- The protobuf sample schema (`route_samples.proto`) is versioned alongside
  `engine_version`.
